# 启动台

一款用 Swift、SwiftUI 和 AppKit 编写的原生 Mac 应用，重现 macOS 15 启动台的全屏应用网格、模糊桌面背景、搜索、分页和文件夹。读取本机的应用名称与图标，点击即可启动真实应用。

## 下载安装

在 [Releases](https://github.com/zhuyonghao/classic-launchpad/releases/latest) 下载对应安装包：M 系列芯片选择 `arm64.zip`，Intel Mac 选择 `x86_64.zip`。解压后将“启动台.app”移到“应用程序”文件夹。需要 macOS 14 或更新版本。

## 构建与运行

需要 macOS 14 或更新版本以及 Xcode Command Line Tools（`xcode-select --install`）。不依赖第三方库，不需要 Xcode 工程。

```sh
./Scripts/build.sh
open "build/启动台.app"
```

生成的应用位于 `build/启动台.app`，可双击运行，也可自行将它移到“应用程序”文件夹。构建脚本只在项目内写入产物，不修改系统启动台或 Dock。应用使用本机临时签名；将它分发给其他 Mac 时，需要另行完成开发者签名及公证。Apple Silicon 与 Intel Mac 均可从源码编译，默认生成当前构建电脑架构的应用。

也可以用 `open Package.swift` 在 Xcode 中打开源码。

## 使用

- **打开或收起**：按 `⌥⌘L`（Option–Command–L），或点击应用图标。全局快捷键在应用运行期间可用。
- **四指手势**：四指捏合打开、四指张开收起；默认开启，在应用运行期间可从其他应用唤出。菜单栏可开关“四指手势”，并查看触控板连接状态。
- **搜索**：直接输入应用名称；支持中文、英文和拼音。按 `Return` 启动选中的应用。
- **选择与分页**：方向键选择应用；点击下方圆点、横向滚动，或按 `⌘←` / `⌘→` 翻页。
- **退出当前界面**：按 `Esc`，先返回上一级或清除搜索，再收起启动台。
- **整理**：拖到图标的左侧或右侧调整位置；拖到图标中央建立文件夹，拖到文件夹上加入。拖至屏幕边缘可跨页移动。
- **添加到程序坞**：直接将应用图标拖到系统程序坞的应用区域；文件夹中的应用和搜索结果也支持。拖到程序坞所在的屏幕边缘，等它显示后放入应用区域。
- **文件夹**：点击打开；点击文件夹名称直接在标题处改名，按 Return 或点击其他位置保存，按 Esc 取消；右键“重命名”也会打开文件夹并编辑标题。拖动成员可以排序，拖到面板外或使用右键菜单可移出。
- **退出程序**：按 `⌘Q`。四指张开或按 `Esc` 只收起界面，应用仍保持运行，以便再次使用手势和全局快捷键。

如果手势同时触发系统界面，请在“系统设置 → 触控板 → 更多手势”中关闭系统的“启动台/应用”和“显示桌面”（名称因系统版本而异）。应用不会自行改动系统手势设置。支持内建触控板和 Magic Trackpad；普通鼠标不支持四指手势。每次捏合或张开只触发一次，抬起手指后可开始下一次；两指缩放、三指操作和四指平移不会触发。

应用将网格与文件夹布局保存在 `~/Library/Application Support/com.local.ClassicLaunchpad/layout.json`。这里只整理启动入口，不会卸载或删除实际应用。

## 应用目录与边界

从本机常用应用目录读取 `.app` 软件包；使用系统提供的应用图标与名称。应用可能因磁盘未挂载、目录位置特殊、权限限制或软件安装方式而未出现在列表中。系统内部服务和嵌套辅助程序不会作为普通应用全部展示。

界面采用经典启动台布局，图标取自当前系统，因此在 macOS 26 上会显示当前版本的应用图标。壁纸为系统提供的桌面静态图像；动态壁纸不可用时显示内置渐变背景。界面打开期间菜单栏和 Dock 自动隐藏，移到屏幕边缘可显示；收起后恢复原来的显示行为。

这是独立实现的启动器，不导入或修改苹果系统启动台的私有数据库。界面和应用管理使用公开 macOS API；全局四指识别通过动态加载系统私有 `MultitouchSupport` 读取触点，因此系统更新后可能需要适配，不适用于 Mac App Store 沙盒分发。框架不可用时，应用仍可通过图标和快捷键打开。触点仅在内存中处理，不保存或上传，不注入键鼠事件。桌面背景效果与屏幕设置、壁纸类型和系统减少透明度选项有关。

## 验证与图标

```sh
./Scripts/test.sh
```

测试脚本先构建，然后执行 `--smoke-test`。测试通过 `CLASSIC_LAUNCHPAD_DATA_DIR` 使用独立临时目录，结束后清理该目录。

应用图标的可编辑矢量源文件为 `Scripts/MakeIcon.swift`；运行 `./Scripts/make-icon.sh` 可以重新生成 `Resources/AppIcon.icns`。

需要验证真实鼠标拖放时，运行 `./Scripts/prepare-ui-test.sh`，再打开 `build/启动台测试.app`。它使用独立测试布局、普通窗口和拖放日志，不会改动正式应用的布局；测试产物均位于 Git 忽略的 `build/` 中。

GitHub Actions 会在 macOS 15 的 Apple Silicon 和 Intel 环境构建、测试并生成应用 ZIP。推送到 `main`、`codex/` 分支或提交 Pull Request 后自动运行。

发布新版本时，先更新 `Resources/Info.plist` 中的版本号，合并到 `main`，再推送对应的 `vMAJOR.MINOR.PATCH` 标签，例如 `v1.1.14`。标签会触发两个架构的构建与测试；校验安装包版本和架构后，工作流上传两份安装包及 `SHA256SUMS.txt`，最后公开 Release。可在 `.github/release-notes/` 添加同名标签的 Markdown 更新说明；未提供时使用 GitHub 自动生成的说明。

## 1.1.1 翻页性能

- 分页保留图标及原生拖拽视图，仅对页面容器做横向移动动画；隐藏页面不参与点击或辅助功能导航。
- 应用扫描期间提前解码并缓存 Retina 图标，翻页不再临时读取应用图标。
- 壁纸在后台按显示尺寸预先模糊并缓存，翻页不执行实时全屏模糊。
- 文件夹分页保持行高稳定；保留“减少动态效果”设置和原生拖放行为。

## 1.1.0 四指手势

- 新增全局四指捏合打开、四指张开收起，菜单开关会自动保存。
- 按设备独立识别四指收缩/扩张，过滤抖动、平移、旋转和错误手指数；拖拽和模态对话框期间暂停响应。
- 支持触控板重新连接、睡眠唤醒后恢复；测试窗口和 smoke tests 不监听真实手势。
- 为四指识别加入合成轨迹回归测试；真实手势仍需在触控板上实测。

## 1.0.1 修复

- 移除悬停导致的整页更新，缓存应用图标，经过图标时不再重复加载所有图标。
- 使用 AppKit 原生拖放，将拖拽数据直接传给落点；拖到图标中央建立文件夹，左右两侧调整顺序。
- 原生拖放结束或取消时清理状态，防止误启动应用；保持网格和图标视图稳定。
- 新增图标缓存、原生粘贴板载荷、任意两个应用合并、文件夹内排序等回归检查。

交互参考：[Apple macOS 15 启动台使用手册](https://support.apple.com/zh-cn/guide/mac-help/mh35840/15.0/mac/15.0)。

## 1.1.2 拖动排序

图标所在的整格和最后一页的空位都接收拖放；图标两侧用于插入排序，中央用于合并文件夹。空位插入到对应位置，超出已有应用数量时放到末尾。文件夹内支持放到目标前后或末尾。

## 1.1.4 页面恢复

关闭后重新显示、或退出后重新启动，恢复上次主页面页码。打开文件夹后返回原主页面，搜索结果的页码不覆盖主页面位置。应用数量变化时自动限制到有效页码。

## 1.1.5 应用扫描

保留 BetterDisplay 等声明后台模式的独立菜单栏应用，补充 CoreServices/Applications 系统应用目录，并支持更深的应用子目录。扫描不进入应用包，避免显示内嵌辅助程序。

## 1.1.6 内存优化

图标位图调整为 200×200（满足最大 100 点的 Retina 显示），缓存限额 24 MiB。模糊壁纸通过 ImageIO 缩略解码，最长边最多 1280 像素，仅缓存一张，并清理 Core Image 中间缓存。图标预加载逐个释放临时对象，显示时保持常驻分页结构；收起时释放页面视图和壁纸引用，重新打开使用缓存图标重建。

## 1.1.7 待机缓存释放

收起 0.3 秒后清空解码图标与壁纸缓存，重新显示前在后台预加载图标。快速收起再打开会取消旧清理任务，避免误删新的缓存。

## 登录时打开

在“系统设置 → 通用 → 登录项与扩展 → 登录时打开”中，添加 `/Applications/启动台.app`。登录自动启动或系统恢复应用时只在后台运行，不弹出全屏界面；四指捏合、⌥⌘L 或点击程序坞图标仍可打开启动台。手动启动应用时正常显示界面。

## 1.1.10 登录启动

识别登录项和系统恢复启动，初始化手势、快捷键与菜单栏后保持后台运行。重复的自动启动事件也不会打开界面；手动启动和点击图标仍正常显示。加入登录启动、系统恢复与手动打开的回归检查。

## 1.1.9 图标点击反馈

以 1.1.7 为基础，按下图标时轻微缩小，松开后放大并淡出，再打开应用；文件夹也有按压与回弹反馈。动画约 0.14 秒，仅更新当前图标的局部状态，点击范围和原生拖放保持原样。开始拖动、切换页面或收起时取消对应反馈；启用系统“减少动态效果”后不缩放、不等待动画。

应用仍不会自动改动系统手势设置。回归检查覆盖图标间隙、移出点击范围、轻微鼠标移动和单次点击启动。

## 1.1.11 四指滑动误触

识别四指同向滑动，即使滑动时指间距收拢或张开，也不会误当作启动台手势。确认滑动后等待全部抬指才重新识别；按手指范围计算捏合的中心移动容差，保留固定拇指、轻微漂移及旋转的正常捏合与张开。新增左右、上下及斜向滑动、抬指恢复和正常捏合的合成轨迹回归检查；真实手势仍需在触控板上实测。

## 1.1.12 程序坞与整理界面

- 应用拖拽同时提供系统文件 URL，支持直接拖入程序坞；保持启动台中的入口与文件夹成员位置，文件夹本身仍只在启动台内整理。
- 文件夹改名支持自动全选原名称、保存与取消，并保留中文输入法的组字操作；1.1.13 起直接在文件夹标题处编辑。
- 排序显示左右插入线，合并显示目标高亮与说明，空位显示虚线落点；拖动的原图标淡化，下方显示当前操作提示。
- 拖到屏幕边缘停留 0.55 秒后翻页，离开边缘或取消拖拽时停止；持续停留可继续翻页。
- 新增文件 URL 载荷、外部拖拽操作、落点边界、状态清理和改名返回顺序的回归检查。

## 1.1.13 标题直接改名

点击文件夹标题即可原地输入新名称，自动全选原名称；Return 或点击其他位置保存，Esc 取消，不再弹出改名卡片。空白名称保留原名称，最多保存 80 个字符。编辑期间点击应用只结束改名，不会误启动应用；切换到其他应用时也会保存名称。

## 1.1.14 拖拽时系统栏闪动

移除拖拽开始和结束时对系统栏显示模式的切换，避免普通整理图标时程序坞和菜单栏突然闪现。拖拽过程保持自动隐藏，拖至对应屏幕边缘时仍可显示程序坞并添加应用。

## 1.1.15 打开速度

- 收起后保留有限的图标缓存（24 MiB）和一张模糊壁纸（最多 8 MiB），覆盖 1.1.7 的立即清空策略；页面视图仍会释放，系统可以按内存压力回收缓存。
- 打开时只优先准备记忆页面的图标及文件夹预览；图标已缓存时直接显示，不再等待全部应用图标。其他页面按访问构建，相邻页面的图标在显示后后台预加载，已访问页面保持原生拖拽视图。
- 应用目录和搜索索引保存在布局文件旁的 `catalog.json`，重新启动先使用缓存再后台更新；常规打开最多每 60 秒重新扫描一次，菜单“刷新应用”仍立即扫描。
- 扫描不再等待全部图标，搜索索引在后台计算；应用更新后按文件修改时间刷新对应图标，布局、文件夹和记忆页保持原有行为。
